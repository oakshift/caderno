    Onde se guardam os dados

    Como ligar ao GitHub

    Se já tem um token para outra app (Descomplica, Horta, Cozinha), pode acrescentar-lhe este repositório em vez de criar outro:

    1. Abra github.com/settings/personal-access-tokens.
    2. Abra o token que já usa e carregue em Edit. Em Repository access, acrescente caderno-dados e guarde. A app encontra-o sozinha.
    3. Ou crie um novo: Generate new token, Only select repositories → caderno-dados, e em Repository permissions → Contents escolha Read and write. Cole-o abaixo.

    O token fica guardado só neste telemóvel.

    Medicação

    O que aparece em Hoje. A hora é a do lembrete no calendário; sem hora, usa a da medicação em Lembretes.

    Dias de treino

    As sessões seguem a ordem dos dias: o primeiro é a Força A, o segundo a B, o terceiro a C.

    Lembretes

    O lembrete mais fiável é o calendário do telemóvel: avisa à hora certa mesmo com esta app fechada.

    Como pôr no Proton Calendar
    1. No Proton Calendar, crie um calendário chamado Plano.
    2. Aqui, carregue em Criar lembretes e guarde o ficheiro plano.ics.
    3. No Proton: Definições → Calendários → Importar, escolha plano.ics e o calendário Plano.
    4. Cada aviso traz o endereço desta app: um toque e está a registar.

    Se mudar os dias ou as horas: apague o calendário Plano, crie-o de novo e volte a importar.
